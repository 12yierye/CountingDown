# 常见问题

## 使用

**卡片不见了？**
托盘图标左键单击切换显示，也可以按快捷键（默认 `ScrollLock`）。位置跑到屏幕外的话，托盘右键「吸附到右上角」强制复位。

**设置里改了没生效？**
全局设置即时生效并写盘。桌面卡片没动的话，先确认它没被隐藏、选中的那一项没被停用。注意**编辑子页里的改动是草稿，要点「保存」才生效**。

**怎么让某一项不跟着全局颜色变？**
进该项编辑页，打开「外观覆盖」总开关，再勾选要改的那几项。没勾的继续跟随全局。

**快捷键按了没反应？**
`ScrollLock` 可能被别的软件占用了。到「系统」里重新录制一个组合键，例如 `Ctrl+Alt+D`。

**卸载后配置还在吗？**
在。配置存在 `%APPDATA%\countingdown\config.json`，卸载不会删，重装不用重新设置。想彻底清掉就手动删这个目录。

**任务管理器里怎么显示「Electron」？**
`pnpm dev` 跑的是 `node_modules` 里的 `electron.exe`，名称来自可执行文件版本信息，开发模式改不了（图标已经是倒数日的）。跑打包版就正常。

## 更新

**检查更新失败，提示「更新源不存在」？**
Release 里没有 `latest.yml`。更新器先取这个清单，只有安装包是没用的。发布流程见 [release-checklist.md](release-checklist.md)。

**提示「返回的是网页而不是清单」？**
镜像拿不到文件时会把自己的首页当 200 返回。先去官方源确认清单已经上传，再试镜像。

**镜像能不能用？**
能用，但它是第三方转发：清单和安装包都从同一个端点来，对方可以同时伪造两者，`sha512` 在这条链路上不提供保护。它解决「连不上」，不解决「不安全」。在意就用官方源或自己托管。

**不想让它联网？**
「关于 → 软件更新 → 更新源」选「不使用在线更新」。此后检查更新和启动时的静默检查都不发请求。

**下载完了装不上 / 校验失败？**
包被改过或没下完整。删掉 `%APPDATA%\countingdown\update\` 里的文件重新下载；仍然失败就用「手动下载」去发布页自己装。

## 开发

**`pnpm install` 报 store 目录不可写？**
见 [notes/build.md](notes/build.md)。

**`pnpm run icon` 失败？**
该脚本依赖 Windows PowerShell 的 `System.Drawing`。失败时托盘会显示空白图标，不影响功能；也可以手动放一张 16×16 的 PNG 到 `resources/tray.png`。

**改了界面怎么验证没跑偏？**
`scripts/` 下有一套可复跑的断言脚本，清单在 [notes/testing.md](notes/testing.md)。
