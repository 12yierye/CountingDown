# 1.2.5

这一版只管三件事：弹窗不再贴顶、底部按钮不再压着边线、预设参数分成了精简与完整两档。

## 新增

- **预设「查看参数」分精简 / 完整两档**：默认精简，四段文字各只列字号与颜色；点「外观参数」那一行右端的「完整参数」，再展开字重、字距与透明度。切换只影响这一处显示，不改动预设本身。

## 变更

- **手动调参弹窗去掉实时预览**：与「外观」全局页保持一致——那边也只有表单，效果看桌面上那张卡片。表单因此铺满整宽，两列控件的空间从 247px 回到 344px，滑条不再拖不开。
- **三个弹窗统一纵向居中**：「调整外观」「手动调参」「查看参数」不再贴顶。内容超过视口时只滚正文，标题与底部按钮留在原地。

## 修复

- 「调整外观」弹窗长到高度上限后偏上、不居中：以前是「距顶 6vh」的顶对齐，视口 961px 时上留 58px、下留 155px。现在上下均分。
- 手动调参弹窗的「取消 / 保存预设」贴着弹窗底边：正文高度上限漏算了内边距（18px×2），外框被限高截断，截掉的正好是底部留白，按钮底边距弹窗底边只剩 2px。改成按主题内边距动态计算后回到 18px。
- 「查看参数」内容较高时整个弹窗超出屏幕下沿、关闭按钮被切：现在正文自己滚，弹窗始终落在视口内。

## 说明

- 精简 / 完整只作用于四段文字的高级参数（字重、字距、透明度）；背景、边框与阴影那一整块两档都保留。每次打开都从精简开始，不记忆上次的选择。
- 手动调参里改的仍是草稿：取消即丢弃，保存只新增预设，不会改动全局外观。
