# 1.2.3

这一版做减法：能收的设置收起来，重复的概念合并掉，窗口里的预览全部删掉——预览现在就是桌面上那张卡片本身。

## 变更

- **桌面卡片实时预览**：编辑、调外观、改文案时卡片实时渲染正在改的内容；进入自动显示，退出按原开关状态还原，预览期间不可关闭。
- **设置分区可折叠**：全站统一成「标题 + 内容」，折叠状态记在本地。
- **显示模式 → 显示精度**：选项改成单字「天 / 时 / 分 / 秒」；单位字并入同一块。
- **编辑页四段化**：基本信息 / 日期与显示 / 文案 / 外观覆盖，外观的 20 多个控件收进「调整外观」弹窗。
- **页面改名**：「行为」→「窗口」，「日期与文案」→「文案与显示」。
- **外观**：取消「高级参数」总开关；字重只剩常规 / 粗体；透明度一律百分比；取色器旁显示 HEX，悬浮看 RGB；文字样式纵向排列。
- **预设可编辑**；「套用」改名「使用」，使用中的按钮禁用。
- **更新源只从预设里选**；侧栏不再折叠。

## 移除

- 全局默认日期（旧配置会把当时生效的日期复制到留空项）。
- 文字总透明度。
- 「过期后显示」开关（文案里写 `{days}`）。
- 设置窗口里所有预览栏。

## 修复

- 调整外观弹窗里「边框 / 阴影」被压扁、内容缺一截。
- 预设详情参数挤成一行、四张卡参差不齐。
- 单位字的「不生效」标灰跟的是全局精度，不是本项精度。
- 新建预设弹窗来源与名称标签不在同一基线。
- 切到「单次」时没补日期，保存后日期跳到 1 月 1 日。

## 说明

- 旧配置自动迁移：日期复制、字重归并到两档、`textAlpha` 丢弃。
- 预览靠桌面卡片，设置窗口压住卡片时先挪开窗口。
- 安装包 **110.7 MB**，仍无代码签名，首次运行提示「未知发布者」属预期。
