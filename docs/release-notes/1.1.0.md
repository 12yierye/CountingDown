# 1.1.0

时间显示改成「天/时/分/秒」而不是冒号，透明度拆成背景与文字两套，预览与设置项做了一轮可读性清理。

## 新增

- **单位字可以换成别的字**（「行为 → 单位字」）：`92天04时36分45秒` 里的「天 / 时 / 分 / 秒」都是可以改的，填 `D` 就得到 `92D`，填 `h` 就得到 `04h`。四项**相互独立**，改一个不会影响另外三个；留空表示这一段不带单位（把「天」留空，「只显示天数」模式就只剩一个数字，因此不再需要单独的「显示天数单位」开关）。单位字本身就起着分隔作用，想要空格或冒号直接写进去即可（写 `"天 "` 或 `"天:"`）。每项倒数日都能在编辑页里单独覆盖这四个字。
- **鼠标点击穿透**（「布局」）：开启后组件完全不接收鼠标事件，点在组件上的点击会直接落到它后面的窗口上，适合组件挡住了后面按钮的场景；问号里写清了「拖动会随之失效」。
- **托盘右键菜单内容可配置**（「系统集成」）：显示/隐藏、吸附到右上角、允许拖动、总在最前、开机自启、快捷键提示都能单独隐藏；「设置」与「退出」是必备入口，始终保留、不出现在设置里。
- **预设主题：保存时先问来源**。点「保存当前外观为预设」会先弹窗选择保存**当前全局外观**、**某个倒数日的外观覆盖**，还是**手动调整所有参数**（选它会直接带到外观页继续微调）。
- **预设主题：查看参数**。内置与自定义预设都多了一个「查看参数」按钮，可以在**不套用**的前提下看清这个预设把字体、背景、圆角、边框、阴影、四段文字样式都设成了什么值，并附上当前各段文案的实际内容。
- **文字透明度**：四段文字各自有透明度，另有一个「文字透明度」总开关可以一起调。

## 变更

- **显示格式不再用冒号**：`天 + 时` 显示成 `92天04时`，`天 + 时 + 分` 显示成 `92天04时36分`，`天 + 时 + 分 + 秒` 显示成 `92天04时36分45秒`。显示模式选项直接展示真实格式模板，换单位字时选项文字会同步变化。
- **透明度拆成两套，互不影响**：背景透明度只管卡片底色，文字透明度只管文字。原先的「组件不透明度」会让整块卡片连同文字一起变淡，已经移除。
- **全局预览统一为「元旦 1 月 1 日」样板**：全局设置各页顶部显示的都是这一份固定样例，只有编辑倒数日时才看该项自己的样子。
- **「过去 N 天」收进问号**：「过期后显示」这一项不再把示例文案写进标题，说明移到了问号里。
- **圆角与内边距拆成两个设置项**，不再挤在一行用斜杠分隔。
- **外观覆盖里不再重复标题**：勾选某项覆盖后展开的编辑器不再重复一遍容器标题，只占必要的高度。
- **偏移量方向说清楚了**：正值统一表示「离开所贴的那条边、朝屏幕内侧移动」。贴右上角时正数即向左、向上，负值才是向右、向下——以前负值的方向是反着的，现在标签与实际行为严格一致（旧配置会自动换算，位置不会跳）。
- **系统集成与关于页不再显示预览**：这两页没有可预览的内容。
- 设置页「实时预览」标题与预览容器之间留出了间距。

## 修复

- **编辑页不再自带吸顶预览**：编辑一个倒数日时，那块预览一直占着屏幕上方，反而挡住了要改的字段；现在编辑页只保留吸顶的返回/保存操作栏，预览统一由全局设置页提供。
- **吸顶操作栏上方的色块**：滚到编辑页下方时，标题栏上方原本会出现一块盖住边框的色块——它来自一个用来「补缝隙」的 `::before` 假元素，而那个假元素自身会被当成滚动内容推出容器外面。现在改成把栏体上提一个 `padding-top` 的高度，滚到底部时正好贴住滚动视口顶端，既没有缝隙也没有多余色块。
- **新建倒数日不再一打开就提示「有未保存修改」**：未启用覆盖时，配置里存的单位字和编辑页草稿拼出来的形状必须完全一致（都写成空串），否则没动过任何东西也会被判成脏的、点「返回列表」直接弹放弃对话框。

## 内部

- **卡片渲染逻辑合并成一份**：桌面组件与设置里的预览改用同一个 `CountdownCard` 组件与 `useCountdownCard` 组合式函数，以前是照抄两遍结构，改一次显示格式就得改两处、漏一处预览就和真实组件对不上。
- **单位字只有一个真源**：`buildPrecisionParts` 按显示模式挑出「天 / 时 / 分 / 秒」四段并各自带上单位字，设置面板的格式模板、显示模式选项文字与编辑页的覆盖都从同一份定义推导。

## 验证

新增可复跑脚本 `scripts/verify-1.1.0.cjs`：67 项断言覆盖显示格式与四个单位字（含单项覆盖、留空、带空格、及「换一个不会连累别的」）、两套透明度互不影响、全局预览样板、偏移量方向（含负值）、真实 `WindowFromPoint` 判定下的鼠标点击穿透开关、托盘菜单可配置项与「设置/退出」常驻、预设保存弹窗与查看参数不误改配置、吸顶操作栏的几何（无多余色块且贴住滚动视口顶端）。
