# 1.2.6

第一次打开不再是一张卡片突然冒出来，而是一段六步引导；安装器进度页那处叠字也一并修掉了。

## 新增

- **首次启动引导**：全新安装后第一次打开会弹一个独立窗口，六步走完——界面语言 → 第一个倒数日（名称、日期、是否每年重复）→ 外观 → 停靠位置 → 演示视频 → 完成。改名字、挑外观时右侧就是真实卡片的等比预览，看到的和桌面上那张一致。每一步都能跳过，改动即时生效，中途关掉也不会白填。
- **演示视频指认「外观与风格」**：最后一步把设置窗口推近到侧边栏第二组，逐项高亮「外观 / 文案与显示 / 预设主题」，并说清这一组就是默认的外观与文案设置。用的是一段可播放、可拖进度的动效而不是录屏：跟着界面语言与四套主题一起变，任何缩放比下都清晰。
- **关于 → 首次设置引导**：随时可以重看。打开时默认选中你现在的语言、倒数日、外观与角落；外观是自己调过的就显示「自定义」。只点「下一步」不做选择，配置一个字节都不会改。

## 变更

- 「重置设置」的细目收进标题旁的问号，正文只留一句后果说明；文案按现在的分组重写，不再出现「日期与文案」「系统集成」这些改过名的旧叫法。
- 「关于」里首次引导的说明压成一行。

## 修复

- **安装器安装开始后文字重叠**：进度页的状态文字在新旧交替时叠成一团（`准备安装目录` 和 `解压 512 / 733` 糊在同一行）。根因是 GDI 绘制文本不带 alpha，半透明色喂进去画出来仍是实心；现在同一时刻只画一行，新行从 0 淡入，高频刷新直接瞬时切换。
- 安装器底部的细节行（文件名、总大小）过长时会压到右侧百分比，改为按剩余宽度裁剪并加省略号。
- **设置窗口右上角按钮的悬停光标乱跳**：圆角把命中区域也裁成了圆角，指针沿按钮边缘移动时会在手型与箭头之间反复切换。补了一层方形命中层，视觉仍是圆角。
- 引导窗口在 1366×768 @125% 这类小工作区下会超出屏幕：尺寸改为按工作区收缩，内容区可滚动。

## 说明

- **恢复默认设置现在要确认两次**：第一次说清后果，第二次只问「真的吗」，且不允许点遮罩关掉。这一步会清空自定义预设，撤销栈也会一起清掉。
- 引导只在全新安装时自动弹出；从旧版本升级上来不会被打断，开机自启的隐藏启动也不弹。
- 卡片样式从 `widget.css` 抽到 [`components/card.css`](../../src/renderer/src/components/card.css)，桌面组件、设置里的预览、引导里的预览共用同一份。
- 安装器回归手段是 `cd-setup --shot fade`。实现细节见 [安装器笔记](../notes/installer.md)，引导的设计取舍见 [首次启动引导](../notes/onboarding.md)。
