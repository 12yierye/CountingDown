# 1.2.4

设置界面整体换了一套皮：Element Plus 的蓝全部拿掉，换成一套中性灰阶，并且多了四种主题可选。

## 新增

- **四套界面主题**——石墨深灰（默认）、纯黑、暖灰、冷白，外加「跟随系统」。在「关于 → 设置界面主题」里用下拉切换，即时生效。
- 主按钮改为反相配色：深色主题用浅银底、浅色主题用石墨底。强调还在，但不刺眼。

## 变更

- **配色重做**：界面里的蓝全部移除，改用中性灰阶。选中态不再靠颜色，而是靠亮度阶梯——未选中透明、悬停一级、选中再亮一档。
- **控件尺寸统一**：所有小号控件 28px 高，输入框和下拉的字号提到 13.5px。
- **圆角收成三档**：控件 8 / 容器 12 / 面板 16，此前同时存在九种取值。
- **下拉面板重做**：圆角浮层，选项 36px 高、悬停有圆角底色。
- **按钮分三层**：主操作反相实心、次要操作 1px 描边、图标与删除无边框。此前实心蓝、蓝描边、灰描边、纯文字四种会同时出现在一屏里。
- **文字样式样张**：显示真实字号（不再统一压到 30px），并铺上卡片自己的背景色——看到的对比度就是桌面上的。
- **预设画廊列宽跟随显示精度**：精度为「天」时一屏能放四张，卡片不再缩在中间一小块。
- **预设详情预览框按精度分档**：低精度用更窄更高的框；同时移除「文案」分组——预设只保存外观，列出文案容易让人以为文案也归预设管。
- 「数字与单位」里的显示精度、单位字补上了设置项名称。

## 修复

- 「调整外观」弹窗外侧出现滚动条：弹窗高度改按视口计算，窗口较矮时不再顶出屏幕。
- 预设详情预览框在精度为「天」时两侧大片空白。
- 深色下卡片底色比浅色亮一档；禁用态输入框反而比正常态更亮。
- 去色后滑块把手与轨道同色，几乎看不见。

## 说明

- 旧配置自动对应：`dark` → 石墨深灰、`light` → 冷白，升级后观感不跳变。「跟随系统」按 Windows 的明暗切换解析成石墨深灰或冷白。
- 主题只影响设置窗口与托盘菜单，不改变桌面卡片。
- 配色现在集中在 [`settings.css`](../src/renderer/src/settings/settings.css) 的令牌区（`--cd-*`），Element 的分档由 `color-mix` 从基础色派生，四套主题各只需定义 20 个色值。
