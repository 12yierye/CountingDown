# 1.2.0

这一版主要解决「设置界面看起来太繁琐」：导航收成分组 + 搜索，预览挪到右侧竖栏，外观页按常用 / 高级分层，并且所有改动都能撤销。顺带把显示模式下放到每个倒数日、重做了通知与托盘开关，也修掉了组件出现在任务栏的问题。

后半程又收拾了一轮细节：编辑页的保存与吸顶栏、预览不再越界、副标题可以写变量，以及把「日期与文案」「关于」这些入口挪到了更顺手的层级。

## 新增

- **撤销 / 重做**：设置界面的所有改动都能用 `Ctrl+Z` 退回、`Ctrl+Shift+Z` 或 `Ctrl+Y` 重来。拖滑块这种连续操作会合并成一步，不会按一次只退一个像素。输入框里的 `Ctrl+Z` 仍然是原生文本撤销。
- **重置本页**：顶栏新增按钮，只把当前页面的设置恢复成默认值，不再只有「恢复默认设置」这一颗核弹。
- **设置搜索**：侧栏顶部可以直接搜「透明」「快捷键」「圆角」这类词，中英文都认。
- **预览侧栏**：实时预览从顶部横条改成右侧竖栏，表单可视高度从 383px 回到约 650px；顶栏「预览」按钮可以随时收起。
- **副标题与状态文案支持变量**：`{days}` 相差天数、`{year}` `{month}` `{day}` 年/月/日、`{week}` 星期几、`{date}` 完整日期。日期类变量跟着**实际生效的日期**走，每年重复的纪念日跨年后 `{year}` 会自己变成新一年。默认副标题下面有一排按钮，点一下就把变量插到文案末尾，不用记语法也不会拼错。
- **每项倒数日单独设置显示格式**：编辑页新增「显示」分区，可以选「跟随全局」或只这一项用「天+时」「精确到秒」等格式。
- **单项当天提醒**：编辑页可以打开「当天提醒我」。这一项**不跟随全局、默认关闭**，与「系统」里的通知总开关是两层。
- **托盘「鼠标点击穿透」开关**：托盘右键菜单可以直接切换穿透；「系统」里还能决定这个菜单项要不要显示。
- **设置导入 / 导出**（「系统」页）：把全部设置导出成一个 JSON 文件，换机、重装或误删时可以导入回来。
- **预设：重命名 / 用当前外观更新 / 复制**：卡片右侧「更多」里可以改名、把预设更新成当前外观，内置预设也能复制一份变成可编辑的起点。

## 变更

- **侧栏重新分组**：8 个平级入口收成 3 组（倒数日 / 外观与风格 / 窗口与系统），当前组自动展开；「关于」不占分组，放在侧栏左下角。
- **「布局」并入「行为」**：位置、偏移、置顶、拖动、穿透、透明现在都在「行为」页；「始终显示在最前」归到「窗口」卡片里，不再孤零零地待在行为页。
- **「系统集成」改名为「系统」**。
- **单位字移到「日期与文案」**：它改的是 `92天` 里那个「天」，和文案、日期同属「显示什么内容」，放在一起更好找。
- **通知改成权限模型**：「系统」里的开关现在是「是否允许本应用发通知」的总闸；当天是否提醒由每一项自己决定，不再有一个含糊的全局「当天提醒我」。
- **透明窗口的说明重写**：「开启后卡片外围能透出桌面，圆角与阴影才是真实效果；关掉则整窗一块不透明。如果卡片后面出现一块浅色方块，关掉它即可」——说清因果关系，不再需要用户猜。
- **外观页分层**：只保留字体、背景、圆角、宽度、文字透明度与四段字号/颜色；边框、阴影、内边距、字重、字距收进「高级参数」。每个分组标题右侧可以单独重置这一组。
- **「日期与文案」归到「外观与风格」组**：它改的是卡片上显示什么，和外观是同一层的东西；「倒数日」组只剩列表。
- **「全局日期设置」改名为「默认日期」**：它本来就是「没单独设置的那一项用它」的默认值，叫「全局」反而让人以为改它会覆盖所有项。编辑页里的「跟随全局日期设置」同步改成「跟随默认日期」。
- **状态文案的三个标签重写**：「未来 / 当天 / 已过去」改成「未到期时 / 当天时 / 过期后」，每行配一句自己的说明。原来把 `{days}` 这种语法写进标签里（「未来（可用 {days} 占位）」），既不解释 `{days}` 是什么，也说不清这行到底什么时候出现。
- **高级参数改成顶部一个开关**：说明里直接列出它会带出哪些项（内边距、边框与阴影、字重、字距、单行透明度）。以前「展开」藏在边框分组里、「收起」又跑到文字分组标题右侧，同一个概念两个位置两套文案。
- **背景透明度独立成行**：它属于「背景」这一级，不再塞在取色器弹层里——藏在那儿时多数人根本不知道有这根滑条。
- **去掉两类多余提示**：全局设置页卡片头的「跟随全局」标签（那是全局页，没有比它更「全局」的东西可跟），以及列表行的「此项已覆盖外观」（那是调试信息）。
- **两个重操作收进关于页**：「恢复默认设置」从导航栏搬到这里，「退出程序」也搬过来并改名「彻底退出」。低频、后果重的操作不该在导航栏上天天晾着，放远一点也免得手滑；左下角只留「关于」一个入口，「关闭」按钮删除（右上角和 `Esc` 本来就能关）。
- **移除外观页顶部的一键配色**：它和「预设主题」页职责重复，套用入口只保留在预设页。
- **预设缩略图改成真实卡片渲染**：不再是手搓的假卡片（原来还硬编码了「128」「5 月 20 日」），背景透明度、边框、阴影、字体、状态行都和桌面一致。当前正在使用的那套会标「使用中」。
- **保存预设不再偷偷改全局**：只有「从某个倒数日复制」时才会多问一句「保存后立即套用到全局」，默认不勾。
- **编辑页「保存」不再顺手返回列表**：点保存只落盘，留在编辑页继续改，标签短暂显示「已保存」；要回列表点左上角。以前点保存等于「保存并退出」，想连改几处就得反复点进来。

## 修复

- **「显示 / 隐藏倒数日」的菜单开关不起作用**：托盘菜单里这一项之前是无条件添加的，「系统」里取消勾选也不会消失。现在会跟着设置走。
- **组件窗口出现在任务栏 / 被当成可关闭的窗口**：创建与每次显示后都会重申 `skipTaskbar`；窗口现在也**不接受关闭**——从任务栏或 `Alt+F4` 关闭时只会隐藏，不会销毁窗口导致卡片消失。
- **「恢复默认设置」后撤销栈会清空**：不会一按 `Ctrl+Z` 又退回重置前的半成品；同时不再整窗重载，界面不会闪一下。
- **编辑页吸顶栏吸顶后「贴边又带一道线」**：滚下去时栏体贴着滚动区顶边，上方两个圆角会被裁掉半截、上边框留一道断头线。现在吸顶时只去掉上方两个圆角与上边框，左右下边框和下方圆角保留，离顶后原样恢复；切换时栏体高度不变，下面的内容不会抖一下。
- **实时预览会溢出预览栏**：把卡片宽度设到 680、字号拉到 120 时，内容会直接糊到栏外。现在预览会按栏的可用尺寸等比缩放（默认设置下接近 1:1），预览列宽度也从固定 260px 改成按窗口比例伸缩。
- **滑动条抓手在两端被切成半个圆**：抓手比轨道宽，值落在最左/最右时有一半伸到轨道外，被容器的 `overflow: hidden` 裁掉。现在轨道左右留出抓手的空间，抓手本身缩小并加了一圈淡色描边。
- **新建倒数日保存后返回列表，刚存的项会消失**：「保存」改成只保存之后，列表仍会把「没保存就离开的新建项」当空白项清理。现在离开时会带上「已经存过了」的标记，不会再误删。

## 说明

- 预设仍然**只保存外观**：文案、显示模式与单位字不随预设切换，预设页底部已经写明。
- 「当天提醒」需要系统通知总开关为开启状态；关机或应用未运行时不会补发通知。
- 文案变量对副标题和三条状态文案都有效；副标题留空时仍然自动显示「几月几日 · 星期几」。
- 「彻底退出」会结束进程、收起托盘图标；只是暂时不想看到卡片，用「显示倒数日」或托盘菜单隐藏即可。
