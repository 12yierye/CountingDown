# 1.2.1

这一版只动安装向导。

上一版把它从 NSIS 换成了自己的小程序：能装、能卸载、能静默升级，但界面还是半成品——一上来就问「装到哪个文件夹」，翻页是硬切的，动画一帧一帧，任务栏里挂的还是 .NET 的默认图标。这一版把向导重做成三步，动画改成按真实时间驱动，图标与程序统一。

安装、升级、卸载的逻辑没有变：升级仍然走 `--silent`，不会让你再看一遍向导。

## 新增

- **第一步「主界面」**：大图标、版本号、一句话介绍，外加三条「装完有什么」。之前从「安装位置」直接开始，用户还没弄清这是什么就被问装哪。
- **「确认」页**：动手前把「装到哪 / 桌面快捷方式 / 开始菜单 / 开机启动」列成清单，最后一步点「安装」才真正开始。改错了点「上一步」回去改，不用取消重来。
- **底栏步骤提示**：`第 1 步 / 共 3 步`，并跟着当前页给一句该页的说明（「装到当前用户目录，不需要管理员权限」「选个位置，其余保持默认就行」）。

## 变更

- **翻页动画重做**：320ms，两页同时横滑、方向相反；动画期间两个按钮禁用，不会连点穿页。
- **滑动的是位图，不是控件** —— 这次最关键的一处。早先直接改两页的 `Left` 让它们滑，而页里的输入框、按钮都是真实子窗口，每帧移动一次就要重排重绘一次，观感就是一格一格硬拽。现在翻页前把两页各 `DrawToBitmap` 拍一张、隐藏真实控件，滑动期间每帧只贴两张图。
- **进度条不再一节一节蹦**：目标值跳变时，显示值按指数逼近滑过去，而不是直接赋值。
- **状态文字交叉淡入**：换文件、换步骤时旧字淡出、新字淡入（200ms），不再瞬间替换。
- **完成页的打勾**：460ms 回弹缩放 + 勾线淡入。
- **按钮与标题栏角标悬停**：120ms 颜色插值渐变，不再是瞬间变色。
- **窗口出现 / 关闭**：220ms / 160ms 淡入淡出。
- **最小化恢复系统原生动画**：无边框窗口默认没有 `WS_MINIMIZEBOX`，最小化是「啪」地消失、DWM 不给过渡；补上这一位之后走系统那套缩放淡出，和应用里其它窗口一致。
- **安装程序图标与程序图标统一**：以前安装器 exe 没挂图标，任务栏和 Alt+Tab 里是 .NET 的默认图标。现在 `icon.ico` 编进 exe，窗体再按自身路径取一次，任务栏 / Alt+Tab / 资源管理器看到的是同一个「27」。

## 修复

- **完成页的打勾压在标题栏上**：自绘的完成页忘了加内容区起点（56px），勾和标题一起往上顶进了标题栏。上一版的截图里其实能看到，只是没人留意。

## 说明

- **安装包 110.7 MB**，比 NSIS 版大 28MB。NSIS 用 LZMA，这里的 payload 是 zip/deflate——这是 .NET 内置能力的上限，level 9 也只省 0.4MB。想省回来得换成 xz 并调用系统 `tar.exe` 解压，代价是多一个外部依赖、进度条变粗，暂时没做。
- **动画按真实耗时算进度再套缓动**，不是「每帧加固定像素」。那种写法在慢机器上会变慢动作、在快机器上一闪而过，时长根本不受控。复测：安装器带 `--shot bench` 参数连翻两次页，输出本机 **avg 14.3ms（70fps）、p95 20.2ms、最大 23.6ms**，没有一帧超过 24ms。
- **安装包仍没有代码签名**，首次运行时 Windows 会提示「未知发布者」，这是预期行为，不是安装包损坏。
- **已知没验到的环节**：沙箱里跑不完整「安装 → 卸载 → 清空」的闭环（后台子进程会被 shell 收走），代码里读不到注册表时会从自身所在目录兜底推断安装路径，但这套兜底还没在真机上跑通过一次。真机首次卸载请留意目标目录是否被清干净。
