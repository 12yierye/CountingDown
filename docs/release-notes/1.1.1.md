# 1.1.1

自定义预设重做：选「手动调整所有参数」会打开一个带动实时预览的弹窗，把参数调好再保存，全程不影响全局外观。同时单位字不再受当前显示模式限制，并修掉了几处编辑页与组件窗口的问题。

## 新增

- **手动调参弹窗**：新建预设选「手动调整所有参数」后，打开的是一个左表单、右实时预览的弹窗，字体、背景、圆角、边框、阴影、四段文字样式一次调到位，右侧预览跟着控件实时变化。**全程不改动全局外观**——取消就什么都没发生，确定也只多出一个预设。
- **预览会显示你起的名字**：在弹窗里输入预设名时，右侧预览的标题同步变成这个名字。

## 变更

- **「保存当前外观为预设」改名为「新建预设」**，弹窗标题同步。那个按钮本来就只负责新建，旧名字容易被读成「立即用当前外观覆盖桌面」。
- **预设名只问一次**：以前选「手动调整所有参数」要先在弹窗里填一遍名字、进了编辑器又要落回「保存预设」。现在手动调整是**先调参数、后填名字**——调完在弹窗里填名称并保存；「当前全局外观」与「某个倒数日的外观覆盖」两个来源仍在来源弹窗里填名字。
- **单位字四项永远可填**（「行为 → 单位字」，以及每项倒数日编辑页里的「单位字覆盖」）：以前「只显示天数」模式下，时 / 分 / 秒三格是禁用的，根本点不进去；现在只把当前模式用不到的段落**淡一档提示**，照样能填，切换到对应显示模式立刻生效。说明文案（中英双语）已同步改写。

## 修复

- **右下角的取消 / 保存按钮跑到弹窗框外面**（连带弹窗底部被切出屏幕）：调参弹窗加进名称表单后，内容高度超过弹窗外框的高度上限，底部按钮于是被顶到边框外。现在正文自己滚动、按钮固定在框内，三种窗口高度下都实测收在框内。
- **调参弹窗关不掉**：点保存后弹窗不消失、仍旧占着屏幕。修复过程中新加的样式规则引起，现已改为只控制高度、不干预弹窗自身的显示与隐藏。
- **开启「单位字覆盖」后，每次进编辑页都显示「未保存的更改」**，点「返回列表」还会弹放弃对话框——即使什么都没改。根因是保存与比较两侧拼出来的配置**键顺序不一致**，而判断脏不脏比的是 `JSON.stringify` 的结果（键序不同即视为不同字符串），只有开启覆盖时才会命中。现在两侧逐字对齐。*（此问题只出现在本轮开发的中间状态，v1.1.0 发布版没有。）*
- **组件窗口消失后，怎么点「显示倒数日」都叫不回来**：窗口一旦被销毁（例如从任务栏把它关掉），旧代码里「显示」会直接放弃——它只翻转一个期望值，不再重建窗口，于是卡片永久消失。现在窗口不存在就重建再显示；开关判断也改为依据**窗口当前是否真的可见**，不再出现「第一次点击没反应、要点两次」。
- **托盘菜单文案与实际状态脱节**：窗口被关掉后菜单还写着「隐藏倒数日」，用户因此找不到把卡片叫回来的入口。现在按窗口真实状态显示「显示 / 隐藏倒数日」，并在窗口消失时立即刷新。
- **任务栏偶发多出组件窗口图标**：组件窗口在显示时与显示后各重申一次「不进任务栏」，降低偶发失效的概率。这一条**没有被验证过**（本机复现不出），能确认的是：即使它再出现，从那里关掉窗口也不再需要重启程序——见上一条。
- **弹窗预览标题不跟着名称变**：样板标题原先只在组件初始化时求值一次，之后输入框怎么改它都不动。现在每次都重新取值。

## 内部

- **外观表单抽成一份被两处复用**：`AppearancePanel` 原来把「控件长什么样」和「一改就写全局配置」绑在一起。现在拆出纯表现层的 `AppearanceFields`（只接收一份外观、改动时抛出新的外观对象，不读配置、不落盘），全局外观页退化成一层薄壳；预设调参弹窗用它操作**深拷贝草稿**，因此「改草稿」在物理上不可能碰到全局设置。
- **宿主外壳单独抽出** `AppearanceGroup`：切换平铺/卡片两种外壳时，`:is` 与 `v-else` 不能凑在同一个位置（Vue 编译期报错，而 `vue-tsc` 查不出来），所以外壳独立成组件。
- **`useCountdownCard` 的 `sampleTitle` 接受取值函数**，不再只接受字符串，供需要实时更新样板标题的场景使用。
- 本轮的排查记录（弹窗盒模型与 `display` 踩坑、JSON 键顺序参与快照比较、组件窗口销毁后的恢复路径、验证脚本的 EPIPE 坑）都写进了 `NOTES.md`。
