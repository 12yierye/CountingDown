# 1.0.3

编辑倒数日时**所见即所得**：改的时候桌面卡片就跟着变，没保存离开会自动回到编辑前。

## 新增

- **编辑时实时预览**：编辑当前显示在桌面的那一项时，桌面卡片实时跟随草稿（名称、日期、文案、外观覆盖都算），标题旁出现「桌面卡片实时预览」标签。编辑期间**不写盘**——点「保存」才生效，点「返回列表 → 放弃修改」立刻回到编辑前。编辑**不是**当前显示项时卡片保持不动，只有编辑页里的预览在变。
- **编辑页头部与预览吸顶**：滚到最下面的外观设置，预览与保存按钮依然可见。
- **新建项放弃编辑不留痕**：点了「新建倒数日」又直接放弃时，那条空白项会被自动删掉。

## 修复

- **任务栏 / 任务管理器不再显示 Electron 默认图标**。窗口现在显式指定应用图标，并设置了 AppUserModelId；`icon.ico` 也从单个 256×256 改成 **16 / 24 / 32 / 48 / 64 / 128 / 256** 七层，任务栏那种小尺寸不再发糊。安装包与主程序 exe 的图标已逐一核对为倒数日图标。

## 说明

开发模式（`pnpm dev`）下任务管理器里的「名称」仍会显示 `Electron`：那读的是 `electron.exe` 的版本信息，开发模式改不了（**图标已经是倒数日的**）。跑打包版就会显示「倒数日」——`pnpm run dist:dir` 后运行 `release\win-unpacked\CountingDown.exe`。
